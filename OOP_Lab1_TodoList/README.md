# ООП — Лабораторная 1: Todo List

WPF-приложение (.NET Framework 4.8) для управления списком задач.

## Открытие в Visual Studio 2022

1. Откройте файл `TodoList.sln`.
2. Убедитесь, что установлена рабочая нагрузка **«Разработка классических приложений .NET»** (для .NET Framework 4.8).
3. Сборка: **Ctrl+Shift+B**, запуск: **F5**.

## Структура (ООП)

| Класс / интерфейс | Назначение |
|-------------------|------------|
| `TodoModel` | Данные задачи, инкапсуляция через свойства с проверкой |
| `TodoService` | Добавление, редактирование, удаление, смена статуса |
| `ITaskRepository` | Контракт сохранения и загрузки |
| `JsonTaskRepository` | Реализация JSON-хранилища |

## Функции

- CRUD для задач (название, описание, даты, приоритет, статус).
- Статусы: Не начата / В процессе / Выполнена.
- Приоритеты: Низкий / Средний / Высокий.
- Сохранение и загрузка списка в JSON; при старте предлагается загрузить файл.
